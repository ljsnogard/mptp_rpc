## 文件命名规范

文件格式一律为 Markdown。

`[主题]-[日期]`，其中日期时间格式为 `YYYYMMDD-hhmm`。

- **模块类文档**：主题取模块名，例如 `connection-20261002-0548.md`；
- **非模块类文档**：主题取文档自身的性质或方向，用小写英文短语，例如
  `outlook-concurrency-20261002-2322.md`。
